# Ответы на Задание 4: Сравнение Git и SVN

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветка — это просто легковесный указатель на конкретный коммит (файл весом в несколько байт), поэтому она создается мгновенно. В SVN ветвление реализовано через полное физическое копирование всей директории проекта на сервере, что требует много времени и дискового пространства.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. SVN — это централизованная система. Весь репозиторий находится на удаленном сервере, поэтому для любого коммита обязательно нужно подключение к сети. В Git же репозиторий распределенный, и коммитить можно локально без интернета.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
SVN может быть предпочтительнее при работе с очень большими бинарными файлами (например, в геймдеве для тяжелой графики и 3D-моделей), которые Git переваривает с трудом. Также SVN удобен для крупных корпораций и банков, где требуется жестко разграничивать права доступа сотрудников к отдельным папкам репозитория, а не скачивать весь проект целиком на компьютер разработчика.
